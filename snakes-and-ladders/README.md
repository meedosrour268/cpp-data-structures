# Snakes And Ladders

C++ coursework source, supplied driver, and test program. Original course interface comments are preserved.

Build and run the supplied tests:

```bash
g++ -std=c++17 snakes.cpp mytest.cpp -o tests
./tests
```

Build the demonstration separately:

```bash
g++ -std=c++17 snakes.cpp driver.cpp -o demo
./demo
```
